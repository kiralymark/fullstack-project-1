### Database connection and using the dotnet user-secrets  
You have to write your values in there:
```  
{
  "ConnectionStrings": {
    "PostgresDb": "Server=localhost;User Id=YOUR_USER;Password=YOUR_PASSWORD;Database=YOUR_DB;"
  }
}
```
  
Database structure:
```   
YOUR_DB  
    users Table    
        id (PK) Field   
        fullname Field
```
